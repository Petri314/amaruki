# Imágenes del blog

Deja aquí las fotos de los artículos. Luego, en el campo **Imagen destacada** del panel
(`blog-admin.html`), escribe la ruta relativa:

```
images/blog/mi-foto.jpg
```

## Recomendaciones

- **Tamaño**: 1200 × 630 px (es la proporción que se ve bien en la tarjeta y al compartir).
- **Peso**: menos de 200 KB. Comprime en <https://squoosh.app> antes de subir.
- **Nombre**: sin espacios ni tildes, en minúsculas. `ansiedad-01.jpg`, no `Mi Foto (1).jpg`.
- **Formato**: `.jpg` para fotos, `.png` solo si necesitas transparencia.

## Cómo subir una foto

1. Copia el archivo a esta carpeta.
2. En VS Code: Source Control → Commit → Sync Changes.
3. Espera ~1 minuto a que GitHub Pages lo publique.
4. En el panel, usa `images/blog/nombre-del-archivo.jpg` como ruta.

Si prefieres no tocar el repo, también funciona cualquier URL pública
(por ejemplo la imagen subida a Instagram o Imgur).
